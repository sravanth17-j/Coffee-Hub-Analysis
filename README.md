# Excel Power Query – Beginner Data Cleaning Project

## Project Overview
This is a beginner-level Excel project created to practice data cleaning and transformation using **Power Query**.  
The main goal of this project was to understand how raw data can be prepared properly before analysis, rather than focusing on advanced formulas or dashboards.

The project demonstrates how Power Query can be used to automate data preparation steps and reduce manual work in Excel.

## Tools Used
- Microsoft Excel
- Power Query

## What I Did in This Project
- Imported raw data into Excel using Power Query  
- Cleaned and transformed the data using Power Query steps  
- Removed unnecessary columns and handled basic inconsistencies  
- Applied structured, repeatable transformations instead of manual edits  
- Loaded the cleaned data back into Excel for further use  

## Key Learnings
- How Power Query stores transformation steps  
- Why data cleaning is an important part of data analytics  
- How automation in Excel reduces errors and saves time  
- How to prepare data properly before analysis  

## Project Level
Beginner

## How to Use This File
1. Download the Excel file from this repository  
2. Open it in Microsoft Excel  
3. Go to **Data → Queries & Connections** to view the Power Query steps  
4. Open the query in **Power Query Editor** to see the transformations applied
